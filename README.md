# Finance Office Tools

一个面向财务办公场景的 Python 自动化工具集合，用于解决日常工作中的重复性任务。
目前包含 Outlook 邮件附件自动收集与 ZIP 自动解压工具。
通过配置文件实现任务规则与路径的灵活管理，便于复用和扩展。
